# Dental Helper

אפליקציית מובייל (PWA) עם שני לחצנים:

1. **צליל כל 3.2 שניות** – לחיצה מתחילה צליל חוזר כל 3.2 שניות, לחיצה נוספת עוצרת.
2. **צליל אחרי דקה** – לחיצה משמיעה צליל אחד אחרי דקה ומסתיימת (לחיצה נוספת מבטלת).

הצלילים מתוזמנים בשעון של Web Audio כך שהתזמון מדויק. בזמן שטיימר פועל המסך נשאר דולק (Wake Lock).

## הרצה מקומית

```bash
python -m http.server 8765
```
